# Karina McGill — Portfolio Site

Personal portfolio for job search and consulting leads (Atom + Bits). Built as self-contained, dependency-free HTML pages: no build step, no frameworks. Open any file in a browser or serve the folder as-is (GitHub Pages works out of the box).

## Structure

```
index.html                          Home page (Option 4: Atom + Bits brand + Swiss case study index)
explorations/
  hero-1-atomic-age.html            Above-the-fold concept A: Atom + Bits core brand
  hero-2-instrument-panel.html      Above-the-fold concept B: instrument panel (dark, diagnostic)
  hero-3-modern-clean.html          Above-the-fold concept C: modern & clean (serif editorial)
  hero-3-swiss-1970s.html           Above-the-fold concept C, revised: 1970s Swiss International Style
```

The `explorations/` folder holds the design directions considered before landing on the current home page. Kept for reference; safe to delete once the direction is final.

## Site map (planned)

Home → About · Case Studies (×5) · Articles

Pages not yet built: About, Case Studies index + 5 case study pages, Articles index. Nav links on `index.html` currently anchor to sections on the home page as placeholders.

## Design system (Atom + Bits brand)

- Colors: ink `#0f171f`, cream `#f8f5ee`, orange `#f16935`, teal `#00b8a1`, card `#efebe1`
- Type: Space Grotesk (400–700) via Google Fonts
- Motifs: orbit rings, pill badges, 16px radius cards, hard 6px offset shadows
- Case studies use a numbered, ruled index (borrowed from the Swiss exploration)

## Content sources

Copy is written in Karina's voice. All metrics ($100M+ program, 300K associates, 25% ticket reduction, 12→50 team growth, $1M savings) are from her verified accomplishments record. Article cards are planned pieces, marked "coming soon."

## Publishing

For GitHub Pages: Settings → Pages → deploy from the branch/folder containing this README. `index.html` becomes the site root.
